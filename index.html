Last.fm JSON export

Download your full Last.fm scrobble history as a JSON file, straight from the Last.fm API. Everything runs in your browser.

✓ Koito-proof: the file can be imported as is into Koito (and any tool that reads the raw user.getRecentTracks format).

Options

Your API key stays in this browser and is only sent to Last.fm. It is never saved. Progress is stored locally, so if you close the tab you can resume by starting again with the same settings.
